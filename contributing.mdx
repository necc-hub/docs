## 小改动：在 GitHub 网页编辑

适合修正错字、命令、失效链接等局部问题：

1. 在 [necc-hub/docs](https://github.com/necc-hub/docs) 找到对应 `.mdx` 文件。
2. 点击铅笔图标 **Edit this file**，Fork 后创建修改。
3. 向 `main` 提交 Pull Request，说明修改原因和影响页面。

网页编辑不会运行本地检查；新增页面、调整导航或修改组件时，请使用本地流程。

## 本地编辑与预览

```bash
git clone https://github.com/necc-hub/docs.git
cd docs
npm ci
npm run dev
```

环境要求：Node.js 20.17–24、Python 3.10+、Git。无需全局安装 Mintlify；`python3` 或 Windows Python Launcher 由 npm 脚本自动调用。

提交前运行：

```bash
npm run check
```

它会同步 PageInsights、运行测试、检查 CSS、Mintlify 配置、frontmatter 和链接。生成器产生的数据和页面挂载更新需要与正文一起提交。

完整环境说明见[本地开发](/development)。

## 写作规范

- **使用主动语态**：写“运行命令”，不要写“命令应该被运行”。
- **直接面向读者**：使用“你”，不要泛泛使用“用户”。
- **保持简洁**：一个句子只表达一个意思。
- **先讲目标**：从读者要完成的任务开始。
- **术语一致**：同一概念不要交替使用不同名称。
- **包含可验证示例**：给出命令时，同时说明预期结果与适用范围。
