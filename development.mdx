## 环境准备

- **Node.js 20.17–24**：以 `package.json` 的 `engines` 为准。
- **Python 3.10+**：用于生成 PageInsights 和文档健康检查。
- **Git**：用于版本管理。

macOS/Linux 需要 `python3`，Windows 需要 Python Launcher（`py -3`）。npm 脚本会自动选择，不要求存在 `python` 命令。

## 安装与预览

所有命令都在本仓根目录（`docs.json` 所在目录）执行：

```bash
npm ci
```

```bash
npm run dev
```

`npm ci` 按 `package-lock.json` 安装锁定版本的 Mintlify 与 PostCSS，无需全局安装 CLI。本地服务器默认在 `http://localhost:3000`，保存文件后热更新；端口被占用时会尝试后续端口。

<Tip>
  本地搜索可能需要 `mint login`。站点结构和页面预览不依赖搜索登录；线上搜索需单独验收。
</Tip>

## 创建新页面

1. 在合适的主题目录创建 `.mdx` 文件。
2. 添加非空 frontmatter：

```yaml
---
title: "页面标题"
description: "说明读者能从本页学到什么"
---
```

3. 在 `docs.json` 的对应导航分组注册页面路径，省略 `.mdx` 扩展名。
4. 修改导航结构时，同步更新 `AGENTS.md`。
5. 运行 `npm run check`，并浏览新页面及上一页/下一页导航。

<Warning>
  空菜单不要上线：注册导航前，请确认页面有实质内容；大二进制按仓库约定托管 CDN，不直接提交到 Git。
</Warning>

## 图片与静态资源

图片统一放入 `images/`，以 `/images/` 开头引用：

```mdx
<img src="/images/NEC-home.gif" alt="示例图片" width="400" />
```

优先使用 WebP 等合适格式并压缩图片。原始 PDF、安装包、CAD、视频等遵循仓库分工，链接主代码仓或 CDN。

## 提交前检查

```bash
npm run check
```

一次执行以下步骤：

1. 回归测试 `npm test`。
2. `npm run insights:generate` 与 `npm run insights:sync`：更新阅读信息并自动维护正文页挂载。
3. `npm run check:css`：解析自定义 CSS。
4. `npm run validate`：校验 Mintlify 配置和页面。
5. `npm run check:docs`：检查导航、frontmatter、内部链接等。

请检查生成器写入的变更，并与正文一起提交。若只想重新生成 PageInsights，可分别运行上述两个 `insights:*` 命令。

<Note>
  外链问题是警告而非统一失败：网络超时和 403/429 可能是环境限制，404 需人工确认。通过健康检查不等于所有外链和浏览器交互均已验证。
</Note>

## 部署

向 `necc-hub/docs` 的 `main` 提交 PR；审查并合并后由 Mintlify 自动部署到 https://docs.newenergycoder.club/。不要直接推送 `main`，也不要将本仓工作分支推送到主代码仓。
